## 1. 프로젝트 정체성
한국어-베트남어 실시간 번역 채팅 플랫폼.
번역 결과를 학습 자산으로 축적하는 언어 생태계.
- 타겟: 50~70대 시니어
- 로그인 없음 (device_id)
- DB 캐싱 우선 → DeepL fallback
- 말풍선: 발신자 기준 (내 메시지=왼쪽)

## 3. 계약서
```
✅ 모든 함수 (ctx) => ctx
✅ throw 금지 → _error 반환
✅ req.text() + JSON.parse()
✅ DB 접근은 connectors/storage.js (getStorage) 통해서만
✅ traceId 항상 포함
✅ HTTP 응답: payload / _error / traceId 구조
❌ 레이어끼리 내부 HTTP 호출
❌ 엔진 안에서 Supabase 직접 createClient
❌ core/ 경로 사용 (brain-engine/core/ 는 삭제됨)
```
