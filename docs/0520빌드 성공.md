## 3. API 라우트 → 엔진 매핑

| API 라우트 | 사용 엔진 | 비고 |
|-----------|----------|------|
| `POST /api/brainpool` | `hajun/router.js` → translate | 번역 메인 |
| `POST /api/brainpool/learn` | `hajun/router.js` | 번역 학습 저장 |
| `POST /api/chat/send` | `hajun/router.js` → translate + `engines/chat/message.js` | 메시지 전송+번역 |
| `GET /api/chat/poll` | `engines/chat/message.js` → GET_HISTORY | 메시지 폴링 |
| `GET /api/chat/trace` | `engines/chat/message.js` → GET_TRACE | 메시지 추적 |
| `POST /api/chat/rooms` | `engines/chat/room.js` → CREATE_ROOM, LIST_ROOMS | 방 생성/목록 |
| `GET/DELETE /api/chat/rooms/[roomId]` | `engines/chat/room.js` → GET_ROOM, DELETE_ROOM | 방 상세/삭제 |
| `POST /api/chat/join` | `engines/chat/room.js` → FIND_BY_CODE | 초대코드로 방 찾기 |
| `POST /api/corenull` | `layers/CoreNullLayer.js` | 방언 사전 |

## 4. 계약서 (절대 위반 금지)

```
✅ 모든 함수는 (ctx) => ctx 형태
✅ throw 절대 금지 → _error 필드 반환
✅ req.text() + JSON.parse() (req.json() 금지)
✅ DB 접근은 connectors/storage.js → getStorage() 통해서만
✅ traceId 모든 요청/응답에 포함
✅ HTTP 응답: 200(에러 포함) 또는 500만
✅ Content-Type: application/json; charset=utf-8

❌ 레이어끼리 내부 HTTP 호출 (fetch('/api/...') 금지)
❌ 엔진 안에서 Supabase 직접 createClient
❌ throw 사용
```
