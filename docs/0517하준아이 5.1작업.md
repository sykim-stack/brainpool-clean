# 🧠 HajunAI v5.1 작업 로그
> 날짜: 2026-05-17

## ✅ 완료된 작업

### 1. BRAINPOOL 번역 엔진 수정
- storage.js: saveTranslationAsset 함수 누락 + saveTranslation 중복 → 전체 교체
- storage.js: device_id 없을 때 _error 대신 _skipSave 처리 (번역 차단 방지)
- hajun/router.js: emotion 엔진 누락 → analyze import 추가
- engines/emotion/analyze.js: 신규 생성
- translation/index.js: detectCtx.payload.language → sourceLang 수정

### 2. HajunAI 확장 프로그램 v5.1 구조 확립
- manifest.json: AI 사이트 host_permissions + content_scripts 추가
  - claude.ai, chatgpt.com, gemini.google.com, perplexity.ai
- background.js: 30분 자동 스냅샷 + AI 탭 스캔 기능
- content.js: AI별 DOM 추출 레이어
- extract-layer.js: 다양한 소스 → BRAINPOOL 표준 형식 변환
- snapshot-layer.js: Gemini 요약 + Supabase 저장

### 3. DB 컬럼 불일치 수정
messages 테이블 실제 컬럼:
  id, project_id, role, content, ai_source, created_at

contexts 테이블 실제 컬럼:
  id, project_id, summary, last_task, updated_at,
  code_context, decisions, architecture, dependencies,
  health_score, phase, current_module, source

snapshot-layer.js 저장 구조 수정:
- messages: project_id, role, content, ai_source 만 사용
- contexts: PATCH → upsert (POST + merge-duplicates)

### 4. Claude.ai DOM 셀렉터 수정
기존 (틀린 것):
  messages: '[data-testid="conversation-turn"]'
  → 결과: 0개

확인 과정:
  [class*="message"] → 20개
  [class*="font-user-message"] → 27개
  [class*="font-claude-response-body"] → 119개

최종 확정 셀렉터:
  messages: '[class*="font-user-message"], 
             [class*="font-claude-response-body"]'
  text: null (textContent 직접 사용)

innerText → textContent 변경 (빈 값 문제 해결)

## 📌 주의사항
- detect.js는 payload.text 를 읽음 (sourceText 아님)
- saveTranslation 실패해도 _error 세팅 금지 (번역 차단됨)
- router.js에 엔진 추가 안 하면 Unknown engine 에러
- Claude.ai는 SPA라 페이지 새로고침 후 셀렉터 재확인 필요
- contexts upsert 시 project_id 반드시 포함
